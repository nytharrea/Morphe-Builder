# Builder-Morphe (FlareSolverr & APKMirror Entegrasyonu)

Bu proje Android uygulamalarını otomatik olarak indirip Morphe yamalarını uygulayan boru hattıdır.

### Değişiklikler ve Yenilikler:
1. **FlareSolverr Altyapısı**: Cloudflare korumaları `FlareSolverr v3.5.2` REST servisi üzerinden aşılmaktadır.
2. **APKMirror Kaynak Sağlayıcısı**: `Instagram` ve `Speedtest` uygulamaları artık GitHub Releases yerine doğrudan APKMirror'dan çekilmektedir.
3. **Termius Kaldırıldı**: Termius uygulaması yapılandırmadan, imza listelerinden ve derleme matrisinden tamamen silinmiştir.
